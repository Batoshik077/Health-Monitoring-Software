# Протоколы действий

Каждое правило тревоги связано с протоколом: что сделать, кого позвать, когда перепроверить.

> ⚠️ Это упрощённые примеры для демо, не медицинские инструкции. В реальной миссии
> протоколы пишут и утверждают врачи полётной медицины. «Медик» команды проверяет тексты
> перед питчем.

Формат:

```yaml
id: hypoxia
rules: [spo2_critical]       # какие тревоги открывают этот протокол
title: "..."
explain: "что происходит простыми словами"
steps:                       # чек-лист, астронавт отмечает «Сделано»
  - "..."
call: cmo                    # кого уведомить: cmo | commander | crew
recheck_after_s: 120         # через сколько система перепроверит показатель
success: "spo2 >= 94"        # условие «стало лучше»
escalate_if_not: commander   # если не стало лучше
on_done: { move_to: storm }  # необязательно: действие после выполнения шагов
```

Успех проверяется так: через `recheck_after_s` правило тревоги больше не срабатывает.
Поле `success` — подсказка для человека.
