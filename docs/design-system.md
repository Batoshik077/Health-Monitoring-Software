# Дизайн-система AstroHealth

Собрана по скиллу `ui-ux-pro-max` (`.claude/skills/ui-ux-pro-max`) из трёх профилей его базы:

| Профиль из базы скилла | Что взяли | Чего избегаем |
|---|---|---|
| **Space Tech / Aerospace** — HUD + Dark Mode | Тёмный «глубокий космос», точная подача цифр, моноширинные метки, тонкая сетка фона | Неоновое свечение, сканирующие анимации (стиль HUD помечен в базе как «высокий риск» для доступности) |
| **Healthcare App** — Accessible & Ethical | Крупный текст (база 16px), контраст ≥ 4.5:1, спокойная палитра | Яркий неон, обилие анимации, фиолетово-розовые градиенты |
| **Real-Time Monitoring** | Семантические цвета статусов, пульсация только у критических тревог | Мигание и анимация без смысла |

## Токены

Заданы в `frontend/src/index.css` (`@theme`, Tailwind CSS 4). В компонентах используются только они — без «сырых» hex.

| Токен | Значение | Контраст с фоном `surface` | Назначение |
|---|---|---|---|
| `bg` | `#0a0c11` | — | фон страницы |
| `surface` / `surface-2` | `#11151c` / `#181d27` | — | панели / вложенные элементы |
| `line` | `#2a3140` | 1.4:1 | декоративные разделители |
| `control` | `#68748a` | 3.9:1 | рамки полей и кнопок (≥ 3:1) |
| `fg` | `#eef2f7` | 16.3:1 | основной текст |
| `muted` | `#a7b0bf` | 8.4:1 | второстепенный текст |
| `subtle` | `#8a95a8` | 6.1:1 | подписи (на `surface-2` — 5.6:1) |
| `accent` | `#60a5fa` | 7.2:1 | ссылки, активное, фокус |
| `accent-strong` | `#2563eb` | белый текст 5.2:1 | основная кнопка |
| `ok` / `warn` / `crit` | `#4ade80` / `#fbbf24` / `#f87171` | 10.5 / 11.0 / 6.6 | статусы |
| `crit-strong` | `#dc2626` | белый текст 4.8:1 | опасная кнопка, баннер тревоги |

Шрифты встроены в сборку (демо работает без интернета): **Inter** — интерфейс, **JetBrains Mono** — цифры (`.num`, табличные цифры) и метки разделов.

## Правила

1. **Статус = иконка + текст + цвет.** Компонент `StatusPill`: «Норма» ✓, «Внимание» △, «Критично» ⬡. Цвет никогда не единственный признак.
2. **Иконки** — только Lucide (SVG, одна толщина линии). Эмодзи не используем. Декоративные иконки скрыты от экранных дикторов (`aria-hidden`).
3. **Цели нажатия ≥ 44px** (`min-h-11`), между ними ≥ 8px.
4. **Фокус виден всегда:** обводка 3px цвета `accent`. Есть ссылка «Перейти к содержимому»; после перехода фокус переносится на основную область.
5. **Движение:** пульсирует только критическая тревога; всё уважает `prefers-reduced-motion`.
6. **Отклик ≤ 100 мс:** галочка шага протокола ставится мгновенно, сервер подтверждает в фоне.
7. **Графики:** у каждого текстовое описание (`aria-label`), подписи осей с единицами, легенда для полосы нормы и порога, тонкая сетка.
8. **Формы:** видимая подпись у каждого поля, подсказка под полем, состояние «Отправляем…» и сообщение об успехе или ошибке.
9. **Навигация:** иконка + текст, активный пункт выделен; на экранах от 1024px — боковая панель, на телефоне — меню.
10. **Пустые состояния и загрузка:** пояснение, что произойдёт, и скелетоны вместо «Загрузка…».

## Проверка

- axe-core (WCAG 2.0/2.1/2.2 A и AA) на всех 10 экранах — **0 нарушений**.
- Телефон 375px: нет горизонтальной прокрутки, все цели нажатия ≥ 24px (порог WCAG 2.2 AA).
- Основной бандл 236 КБ (было 589 КБ): экраны с графиками загружаются отдельно.
