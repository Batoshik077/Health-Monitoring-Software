# Что нужно изучить команде

Начните с раздела 1: он займёт полчаса и определит всё остальное.

## 1. Правила хакатона (в первую очередь)

- [ ] Точный текст задачи и что просят: прототип, концепт или исследование
- [ ] Критерии оценки и их вес
- [ ] Формат сдачи: слайды, видео (какой длины), ссылка на репозиторий, живое демо
- [ ] Дедлайны сдачи и питча, время на питч, будут ли вопросы
- [ ] Можно ли использовать заготовки кода и ИИ-инструменты
- [ ] Ресурсы от организаторов: датасеты, API, ментор-врач
- [ ] Кто в жюри: инженеры, врачи, бизнес

## 2. Космическая медицина

Готовые ответы с источниками — в [`thresholds-and-facts.md`](thresholds-and-facts.md).

- [ ] Сердце и сосуды: перераспределение жидкости, пульс и давление
- [ ] Кости и мышцы: скорость потери, тренировки как защита
- [ ] Радиация: источники, дозы на МКС и в полёте к Марсу, лимит NASA
- [ ] SANS: изменения зрения
- [ ] Сон: почему нарушается
- [ ] Психология: изоляция, стресс, как это оценивают
- [ ] Иммунитет: почему ослабевает в полёте
- [ ] Нормы показателей и шкала NEWS2
- [ ] Допустимые CO₂, O₂, давление на станции
- [ ] Как мониторят сейчас: Astroskin / Bio-Monitor, Crew Medical Officer, Flight Surgeon
- [ ] Задержка связи с Луной и Марсом, соединение Марса с Солнцем, DTN

## 3. Данные

- [ ] Как сгенерировать правдоподобные мок-данные (например, `neurokit2` для ЭКГ)
- [ ] Открытые датасеты: PhysioNet, NASA Open Data Portal, Life Sciences Data Archive
- [ ] Как меняются показатели при гипоксии, тахикардии, стрессе — для сценариев

## 4. Технические знания по ролям

**Backend**
- [ ] FastAPI: REST, WebSocket, фоновые задачи (asyncio)
- [ ] SQLite (sqlite3 или SQLAlchemy)
- [ ] Очередь с задержкой для имитации связи
- [ ] Z-score и EWMA (скользящее среднее)

**Frontend**
- [ ] React + Vite + TypeScript
- [ ] WebSocket и графики в реальном времени (Recharts или ECharts)
- [ ] Tailwind, тёмная тема

**Общее**
- [ ] Git: ветки и работа без конфликтов
- [ ] Запуск одной командой (Docker Compose или скрипт)

## 5. Для питча

- [ ] 2–3 ярких факта для начала выступления
- [ ] Реальные случаи (тромб на МКС, 2020)
- [ ] Похожие решения и чем наше отличается
- [ ] Применение на Земле: Антарктида, подлодки, удалённые районы
- [ ] Ответы на вопросы жюри: отказ датчика, ложные тревоги, почему не всё на Землю, защита данных
